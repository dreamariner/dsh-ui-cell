# 016 · fix · Resizable 的拖动契约

## 背景

文档站上拖 Resizable 的分隔条，两个问题叠在一起：

1. **拖动不跟手**：分隔条与光标之间有固定偏移，拖起来越拖越偏。
2. **松手后还在跟着鼠标动**：拖过一次之后，只要鼠标移动，面板宽度就跟着变，极其误触。

## 现场量出来的

| 项 | 实测 | 应然 |
|---|---|---|
| 状态里的左栏百分比 | 45% | — |
| 实际渲染出来的左栏宽度 | **71.93%** | 45% |
| 光标往左拖 80px，分隔条 | **往右挪了 20px** | 往左挪 80px（分隔条中心对光标） |
| 松手后再移动鼠标 | 面板继续变 | 不变 |

## 根因（三条，互相独立）

### 一、百分比与渲染宽度对不上（flex 模型错）

左栏写的是 `style={{ flexBasis: '45%' }}`，而 `.pane` 的 CSS 是 `flex: 1 1 0`。
flex-basis 的 45% 配上 `flex-grow: 1`，剩余的 55% 空间会被**两栏按比例分**，
于是左栏实际拿到 45% + 27.5% = **72.5%**（实测 71.93%，差的是分隔条那几像素）。

结果是状态里的百分比根本不代表渲染出来的宽度，分隔条画在一个「百分比以为在的地方」，
拖动时每一步都在错的基础上再错一点。

### 二、百分比是按分隔条左边缘算的

```
percent = (clientX - rect.left) / rect.width
```

分隔条有宽度，光标落在条上时，条的中心比它的左边缘靠右半个条宽。
按左边缘算，分隔条与光标之间永远差半个条宽。

### 三、拖动状态收不掉（粘滞的来源）

原实现把 `pointermove` / `pointerup` 挂在 `window` 上，靠 `pointerup` 收尾。
**指针在窗口外松开时，页面收不到 `pointerup`**（鼠标按钮是在浏览器窗口之外释放的），
拖动状态就永远挂着 —— 之后每一次 `pointermove` 都会改布局，这就是「只要鼠标移动就跟着动」。

## 方案

### 一、百分比与渲染宽度对齐

左栏改成**不吃 grow**：`flexBasis: <percent>%` + `flexGrow: 0` + `flexShrink: 0`，
右栏继续 `flex: 1 1 0` 吃剩下的空间。此时 flex-basis 的百分比就是左栏的真实宽度占比 ✓。

### 二、百分比按「分隔条中心对准光标」反解

```
左栏宽 = 光标 x - 容器左沿 - 分隔条半宽
百分比 = 左栏宽 / 容器宽
```

分母用**容器宽**（flex-basis 的百分比就是按容器算的，不是按两栏之间的轨道算，
轨道要减掉分隔条），分子先减掉分隔条半宽 —— 两者配套，分隔条中心就正对光标。

### 三、拖动收尾三路兜底

- **指针捕获**（`setPointerCapture`）：光标移出分隔条、甚至移出窗口，事件仍然送到它，
  松手一定收得到（这是「窗口外松手」的正解）。
- **`pointercancel`**：浏览器把手势抢走时（原生拖拽、滚动竞争）也会收尾。
- **窗口失焦**（`blur`）：切标签页、弹系统框，页面收不到 pointerup 时的最后一道兜底。

另外：拖动中 `preventDefault` + `document.body.style.userSelect = 'none'`（别在拖动时选中文本），
拖动结束与组件卸载都要把光标与选中态还原。

## 顺带修掉的

- 演示的容器给了 `height: 130` 但没让 Resizable 撑开，组件缩成 22.5px 高（拖拽区只有一条缝）。
  容器改成 flex，Resizable 撑满 128px ✓。
- 分隔条加 `touch-action: none`：触摸设备上别让浏览器把手势吃掉当滚动。
- 分隔条补 `aria-valuenow` / `aria-valuemin` / `aria-valuemax`（`role="separator"` 的可访问值）。

## 护栏

新增 `tests/resizable.spec.tsx`（9 例），钉住三条契约：

1. 左栏的 flex-basis 等于百分比，且 grow / shrink 都是 0（百分比失真回归）
2. 拖动时百分比按「分隔条中心对准光标」算（算式写死：光标 200、容器宽 400、分隔条宽 5
   → 49.375%）；按下时必须发生指针捕获；百分比被夹在 min/max 之间
3. 松手后移动鼠标不再改变布局；没按住时移动鼠标不改变布局；
   `pointercancel` 与窗口失焦都能收掉拖动状态；拖动结束光标与选中态都还原

| 项 | 修前 | 修后 |
|---|---|---|
| 状态 45% 渲染成 | 71.93% | 45% ✓ |
| 光标往左拖 80px | 分隔条往右挪 20px | 分隔条往左挪 80px ✓ |
| 松手后移动鼠标 | 面板继续变 | 不变 ✓ |

实机核对（文档站）：拖动前后分隔条中心 522.6 → 442.6，与光标位移一比一；
