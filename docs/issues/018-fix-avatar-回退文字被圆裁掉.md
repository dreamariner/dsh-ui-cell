# 018 · fix · Avatar 的回退文字排版

## 背景

文档站上检查 Avatar 演示，发现两处不对：

1. 两个字的回退（「助手」「回退」）看着像**缺笔画** —— 字的左右两端被圆形裁掉了；
2. 图片那张在有的浏览器里渲染成**圆角方块**而不是圆形。

## 根因

### 一、圆形头像能放文字的宽度是「内切正方形」

圆形里能完整显示的区域是内切正方形，边长 = size/√2 ≈ **0.707 × size**。
32px 的头像 → 可用宽度只有 **22.6px**。

原来的回退字号是固定比例 `0.42 × size`（13px），一个字占 13px ✓ 没问题，
**两个字就占 26px**，再加 `.fallback` 的左右各 2px 内边距 → 30px ✗ 超出 22.6px → 被裁。

实测：改前「助手」两个字的盒子宽 **30px**（内切正方形 22.6px）。

### 二、圆角只写在父级的 overflow 裁剪上

`.avatar { border-radius: 50%; overflow: hidden }` + `.image { width/height: 100% }`。
靠父级裁剪替换元素（`<img>`）在个别引擎里会漏，图片就露出方角。

**上游 DSH 自己的做法**（`ui-settings-account/src/client/AccountAvatar.module.css`）：

```css
.image { display: block; width: 100%; height: 100%; border-radius: 50%; corner-shape: round; object-fit: cover; }
```

圆角写在 **img 自己身上** ✓ —— 最稳的做法 ✓（父级的裁剪留着当双保险）。

## 处置

### 一、回退字号按字数缩放

| 字数 | 字号比例 | 32px 头像里的文字宽度 | 内切正方形 |
|---|---|---|---|
| 1 | 0.42 | 13px | 22.6px ✓ |
| 2 | 0.33 | 22px | 22.6px ✓ |
| 3 | 0.22 | 21px | 22.6px ✓ |
| >3 | 只取前 3 个字 | — | — |

比例的来源：`n 个全角字 × 字号 ≤ 0.707 × 边长`（1 个字另给一档好看的 0.42）。
另外把 `.fallback` 的左右内边距去掉（2px × 2 也会把文字推出可显示区）。

### 二、图片的圆角落到 img 自己身上

照上游 AccountAvatar 的写法（`border-radius: 50%` + `object-fit: cover`），
父级的 `border-radius` + `overflow: hidden` 保留当双保险。

## 复审补记：回退不能只是浮在页面上的裸文字（2026-11-18，同一 issue 第二轮）

改完上面两条再看，亮色主题里的回退头像**整个圆形是看不见的** —— 只剩一个字浮在页面上：

| token | 亮色 | 暗色 |
|---|---|---|
| `--dsw-alias-bg-layer-3`（原回退底色） | rgb(255,255,255) = **页面白底** | rgb(53,54,56) ✓ 看得见 |
| `--dsw-alias-border-l3` | rgba(0,0,0,0.12) ✓ | rgba(255,255,255,0.16) ✓ |
| `--dsw-alias-bg-skeleton` | rgba(0,0,0,0.04)（太淡） | rgba(255,255,255,0.08) |

处置：回退改成「**有底色 + 一圈描边**」的圆形（描边用 `border-l3`，两套主题都看得见），
表面画在 `.fallback` 自己身上（图片那张不描边，保持干净）。

另外把演示也理顺了 —— 原来四个头像并排排开，看不出哪个是哪个：

- 每种情况加一行标注（首字母回退 / 多个字 / 图片 / 图片加载失败 → 自动回退）；
- 图片那张从「纯色方块」换成**渐变人像**的 SVG（原来那张看起来就像一个空色块，
  容易被当成「图片没加载出来」）。

实测（两套主题）：回退 = 白底 + 12% 黑描边（暗色 = 灰底 + 16% 白描边）；
「助手」「回退」两字缩到 11px，文字宽 22px ≤ 内切正方形 22.6px ✓ 不再被裁。

## 护栏

新增 `tests/avatar.spec.tsx`（9 例）：

- 字号按字数档走（13px / 11px / 7px），且「n 个字 × 字号 ≤ 0.707 × 边长」恒成立；
- 超过 3 个字只取前 3 个；非文本回退（图标）不截断、字号走默认档；
- 有 `src` 时渲染图片，图片 `error` 后回退到回退内容；
- 样式表契约：圆角写在 `.image` 上、回退文字不留左右内边距、回退有可见的圆形（底色 + 描边）。

## 附：怎么验的（逐像素）

没有靠肉眼。写了��个最小 PNG 解码器（`zlib` 解 IDAT + 反滤波）读截图的像素：

- 圆角归属：把父级与 img 的圆角都清零 → 形状变**方角** ✓（说明圆角确实在起作用）；
  单独把 img 的圆角改成 0 → 形状不变 ✓（说明当前引擎是父级裁剪在起作用）；
  再把 img 的圆角改回 50% → 仍是圆 ✓（双保险生效）。
- 圆形判定：沿每一行读原始像素，边缘每行只推进约 1px ✓（圆形边缘是渐进的，
  圆角方块则是直边 + 固定圆角）；把 img 隐藏后形状消失 ✓（确认是 img 自己画的）。
